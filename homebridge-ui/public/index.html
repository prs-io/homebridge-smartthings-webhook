📖 How to Get a Public HTTPS URL ▼

SmartThings requires a public HTTPS URL to send webhook events. Choose one of these options:

Option 1: ngrok (Easiest - Free)
  1. Sign up at ngrok.com (free account)
  2. Download and install ngrok
  3. Run: ngrok http 3000
  4. Copy the https://xxxxx.ngrok-free.app URL
Note: Free ngrok URLs change on restart. Consider a paid plan for a static URL, or use a custom domain.
Option 2: Cloudflare Tunnel (Free - Permanent URL)
  1. Sign up at Cloudflare and add your domain
  2. Install cloudflared: Guide
  3. Create tunnel: cloudflared tunnel create homebridge
  4. Route traffic: cloudflared tunnel route dns homebridge webhook.yourdomain.com
  5. Run: cloudflared tunnel run --url http://localhost:3000 homebridge
Option 3: Let's Encrypt SSL + Port Forwarding
  1. Get a domain name (or use a free DDNS like DuckDNS)
  2. Forward port 443 on your router to your Homebridge server
  3. Install certbot: sudo apt install certbot
  4. Get certificate: sudo certbot certonly --standalone -d yourdomain.com
  5. Use a reverse proxy (nginx/caddy) to terminate SSL and forward to port 3000
Tip: Caddy automatically handles Let's Encrypt: caddy reverse-proxy --from yourdomain.com --to localhost:3000

📖 How to Create a SmartApp ▼
🎥 Watch Video Tutorial (4:05 - 6:07) ↗
  1. Visit the SmartThings Developer Workspace
  2. Create a new project:
    • Click + New Project
    • Select Automation for the SmartApp
    • Give it a name (e.g., "Homebridge SmartThings")
    • Click CREATE PROJECT
  3. Register the App:
    • From project Overview, click REGISTER APP
    • Select Webhook Endpoint as hosting type
    • Enter your Target URL (your Server URL + /smartapp)
    • Ensure URL is HTTPS
  4. Configure App Details:
    • Add a display name and description
    • Select OAuth2 scopes: r:devices:*, x:devices:*, r:locations:*
    • Select Multiple Instances if needed
  5. Click SAVE - You'll receive your Client ID and Client Secret
  6. Copy the App ID from the app overview page
⚠️ Important: Save your Client ID and Client Secret immediately - the secret is only shown once!

Waiting for SmartApp Installation

Install the SmartApp from your SmartThings mobile app to complete setup.

Install SmartApp

Follow these steps to complete the connection:

  1. Open the SmartThings mobile app
  2. Go to Menu → SmartApps → Add (+)
  3. Find and install your Homebridge SmartThings SmartApp
  4. Select the devices you want to control via HomeKit
  5. Complete the installation
